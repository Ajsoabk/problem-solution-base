安全与 token
网关 token 只从本机读取，不下发到浏览器

          

          
如果网关配置了 token，在启动后台前设置环境变量：

          
$env:LLM_GATEWAY_TOKEN="你的网关token"
node tools/admin-server.mjs

          
也可以写到 admin/gateway-token.txt（已加入 .gitignore）。

          

          
    
            
  • 后台只监听 127.0.0.1，拒绝非回环 Host。
    • 
            
  • 不读取任何厂商 API Key，也不把网关地址发到公网。
    • 
            
  • 题目改动先校验，再原子写入；构建失败自动回滚。
    • 
            
  • 删除的题目移入 tools/.tmp/trash/，不会直接消失。
